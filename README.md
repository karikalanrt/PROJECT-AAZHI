# 🛰️ PROJECT AAZHI — Satellite Intelligence Platform

**Autonomous Multi-Spectral & Synthetic Aperture Radar (SAR) Earth Observation Platform for Disaster Management**

---

## 🌟 Key Features
- **Engine 1: Quantitative Spectral Physics** — NDVI, NDWI, MNDWI, NDBI index calculations and ground resolution scaling.
- **Engine 2: On-Device Vision AI** — Multi-spectral anomaly interpretation and disaster damage assessment.
- **Autonomous Radar Sentinel** — Live SAR flood footprint detection, severity calculation, and tactical auto-alerts.
- **PWA Offline Support** — Progressive Web App offline caching and real-time network connectivity auto-switching.
- **Evacuation Pathfinding** — Dijkstra optimal routing on satellite terrain maps.
- **Audio Dispatch** — Multi-lingual synthesized voice dispatch briefings for field rescue teams.

---

## 🚀 Local Execution
To run locally in offline mode:
```bash
# Option 1: 1-Click Launcher (Windows)
Double-click `run_offline.bat`

# Option 2: Command Line
pip install -r requirements.txt
streamlit run app.py
```
